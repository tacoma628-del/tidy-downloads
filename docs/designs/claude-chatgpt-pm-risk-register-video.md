## Problem Statement
David makes ~10-minute instructional YouTube videos about Claude, aimed at people who
aren't career engineers. This video's audience is production project managers, and the
goal is to show a concrete, non-abstract example of Claude incorporating ChatGPT into a
real workflow — not just "look, two AIs talking."

## What Makes This Cool
Two differently-trained models catch different blind spots — the same reason teams pull
in an outside reviewer for risk brainstorming instead of just re-reading their own list.
Claude drafts a risk register solo on screen, then ChatGPT is brought in specifically as
devil's advocate on *Claude's own draft* — the whoa moment is watching it catch something
the first pass missed, fast enough that the PM immediately sees the time saved.

## Constraints
- ~10-minute video format, needs to be clean to film and narrate live.
- Audience is non-technical (production PMs), so the demo has to read as "I could use
  this Friday," not "here's some code."
- Needs an `OPENAI_API_KEY` (not yet confirmed as set up).
- Default stack is Python for glue work like this.

## Premises
1. The real problem is showing PMs a fast, concrete multi-model workflow — not proving
   "AI collaboration" as an abstract concept. — Agreed.
2. A risk register is a good demo task: PMs immediately recognize it, and "did it miss
   anything" is an easy on-camera gut-check. — Agreed.
3. Nothing in this repo currently touches PM-style docs — this is new work, not a
   refactor of `tidy_downloads.py` / `tidy_photos.py`. — Agreed.
4. Since the payoff is *speed*, the build needs to be scriptable/automatable, not manual
   copy-paste between two browser tabs — that would undercut the whoa. — Agreed.

## Approaches Considered

### Approach A: Manual dual-tab
Draft in Claude, copy into ChatGPT's web UI with a critique prompt, screen-record both.
- Effort: S. Risk: Low.
- Pros: Zero setup, no API keys, most relatable to a non-technical PM who'd replicate it
  themselves with free accounts.
- Cons: Manual copy-paste undercuts the chosen "speed" whoa; messier to film cleanly.
- Rejected: doesn't deliver the whoa moment the user picked (speed).

### Approach B: Python script, both APIs
Three steps in one script: Claude API drafts the risk register from a project brief,
the OpenAI API critiques the draft, then Claude merges the critique into a final list
(a third, short Claude call — same model that drafted it, now reconciling feedback).
- Effort: M. Risk: Low-Medium (needs `OPENAI_API_KEY`, not yet confirmed set up).
- Pros: Strongest version of the chosen "speed" whoa; fits default Python stack;
  scriptable and rerunnable, so a bad take can just be rerun rather than reshot live.
- Cons: Requires wiring up a second API key before filming. Three sequential API calls
  is more moving parts than a two-call design, but the merge step is required by the
  stated Success Criteria (a real "merged final list," not just two lists side by side).

### Approach C: Claude Code shells out to Codex CLI
Claude Code drafts the register, then calls OpenAI's `codex exec` CLI to critique it,
live in one session.
- Effort: M. Risk: Medium (needs Codex CLI installed + `codex login`; Codex is tuned for
  code review, so prompting it for PM content is a stretch).
- Pros: Fun "meta" framing — Claude Code visibly orchestrating a rival tool.
- Rejected: extra install/auth dependency and off-target model tuning outweigh the
  novelty for this video.

## Recommended Approach
**B — Python script calling both APIs.** Delivers the "speed" whoa most directly, matches
the user's default stack, and produces a reusable asset instead of a one-off screen
recording.

## Success Criteria
- Script runs end-to-end in one command and produces a merged risk register in well
  under a minute.
- Output clearly separates three stages: Claude's solo draft, ChatGPT's critique, and
  the merged final list (produced by a third, short Claude call reconciling the
  critique into the draft).
- During pre-production dry runs (not necessarily the filmed take), ChatGPT's pass
  reliably surfaces at least one risk category genuinely missing from Claude's draft.
  **Fallback if a specific take doesn't produce a catch:** iterate the project brief
  during rehearsal until the gap is reliable, then film that brief — never stage or
  hand-edit a fabricated catch into the on-camera output.

recorded video, published to YouTube.
